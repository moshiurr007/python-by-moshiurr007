### Quick Sort Algorithm Implementation

#### Challenge

Implement the Quick Sort algorithm to sort a list of integers without using Python's built-in sort() or sorted() functions.

#### Instructions

1. Define a function named quick_sort.
2. The function should take a list of integers as input and return a new sorted list.
3. Choose a pivot value from the first or last elements of the input list.
4. Partition the input list into three sublists: elements less than, equal to, and greater than the pivot.
5. Recursively call quick_sort to sort the sublists and concatenate them to produce the final sorted list.

#### Example

Input : [5, 3, 2, 1, 4]

Output : [1, 2, 3, 4, 5]
